# DOAB (दोआब) — Two Waters
**Detect → Order → Alert → Back-check**

DOAB is a real-time civic disaster resilience and municipal water-dispatch coordination platform engineered for extreme climate vulnerabilities (flash floods, urban waterlogging, drought shortages, and water tanker supply lines).

Developed by **Team Contrarians** for WeMakeDevs Hackathon.

---

## 🌊 Core Capabilities & The Loop

1. **Detect**: Ward-level telemetry and hydrological predictive modeling dynamically flag inundated arteries and drought-stricken zones.
2. **Order**: Dispatch and work-order pipeline instantly assigns civic response units, plumbers, suction pumps, or emergency water tankers.
3. **Alert**: Real-time broadcast system warns citizens and reroutes delivery/two-wheeler riders around hazardous corridors.
4. **Back-check**: Ground-truth validation and citizen back-check feedback continuously recalibrate ward safety scores.

---

## ⚡ Key Highlights & Architecture

- **Dual Climate Dynamics**: Seamlessly toggle between **Flood Resilience Mode** (Aqua/Porcelain) and **Drought Scarcity Mode** (Amber/Baked Earth) across all telemetry, routing, and incident matrices.
- **Precision Safe Routing**: Multi-modal navigation avoiding high-risk flood zones and waterlogged roads, with vehicle clearance thresholds and elevation biasing.
- **Zero-Jerk Route Transitions**: Hardware-accelerated CSS keyframe transitions and synchronous pre-paint scroll coordination (`scrollbar-gutter: stable`).
- **Unified Auth & Preferences**: Google Firebase Authentication, saved session hints, custom audio feedback toggles, and user-configurable routing parameters.
- **Responsive & Touch-First**: Optimized for desktop operations centers, tablets, and field mobile touch screens.
- **Voice AI Operations Copilot**: Interactive audio telemetry assistant with speech synthesis and real-time civic incident query handling.

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS v4, Framer Motion
- **Geospatial & Mapping**: Leaflet, React-Leaflet, GeoJSON Ward Boundaries
- **Authentication**: Firebase Auth (Google OAuth & Email/Password)
- **Icons & UI**: Lucide React, Custom Canvas Particle Engine, Micro-sound FX Engine

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm or pnpm

### Installation & Local Run
```bash
# Clone the repository
git clone https://github.com/AWDAX/DOAB-Platform-.git
cd DOAB-Platform-

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build
```bash
npm run build
```
