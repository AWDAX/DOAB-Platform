# DOAB-AI-flood-and-drought-response-for-Indian-cities
DOAB (दोआब, "two waters"): Detect, Order, Alert, Back-check. AI flood-and-drought response for Indian cities — ward-level risk maps, plumber/tanker dispatch, safe rerouting for riders, and citizen photo verification. Built on AWS for Environmental Hacks, Track 02: Heat &amp; Water.
