# DOAB (दोआब): "two waters"
Too much water, too little: Detect → Order → Alert → Back-check.

## The loop
- Detect: risk model flags a ward
- Order: dispatch or bounty work order to a plumber or tanker
- Alert: citizens and riders warned and rerouted
- Back-check: post-event "was the road flooded?" tap and trust score feed the model

## Built on AWS
Bedrock · Lambda · API Gateway · S3 · DynamoDB · Location Service · Rekognition
